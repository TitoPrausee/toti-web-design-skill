## The Creative Website Manual™
- **URL:** https://www.creativewebmanual.com/
- **Award:** SOTD Dec 23, 2025
- **Creator:** Huy Nguyen, MONOLOG, Ivor J.
- **Colors:** `#070707` (near-black), `#EAEAEA` (off-white) — pure monochrome
- **Fonts:** Editorial serif/display
- **Layout:** Grid-based, magazine-style, structured chapters
- **Animations:** Scroll-driven reveals, typographic transitions
- **What Makes It Special:** A visual and technical exploration of how creative websites are crafted — from concept and grids to typography and motion. Pure 2-color monochrome system.
- **Techniques to Steal:**
  - 2-color monochrome system (`#070707` + `#EAEAEA`)
  - Magazine-style grid layout
  - Chapter-based content structure
  - Typographic transitions

```css
/* The Creative Website Manual monochrome */
:root {
  --bg: #070707;
  --text: #EAEAEA;
}
```

## 365 — A Year of Cartier
- **URL:** https://www.awwwards.com/sites/365-a-year-of-cartier-5
- **Award:** SOTD, behind-the-scenes feature
- **Creator:** Immersive Garden
- **Colors:** Cartier brand — deep red, gold, black
- **Fonts:** Luxury serif + clean sans-serif
- **Layout:** Netflix-style browsing, chapter grid, endless scroll articles
- **Animations:** Page transitions, scroll animations, WebGL image distortions, 3D jewellery
- **What Makes It Special:** Digital version of Cartier's annual print publication. "Like flipping through a magazine." 32 articles from 15 reusable components. "Read" state marks thumbnails.
- **Techniques to Steal:**
  - Netflix-style content browsing grid
  - Endless scroll article loading
  - Read-state visual tracking (folded corner mark)
  - Chapter-based sidebar navigation
  - Modular component reusability
  - Hybrid HTML + WebGL (content accessible, WebGL enhances)
